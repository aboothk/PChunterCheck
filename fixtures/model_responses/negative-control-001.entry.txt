# Calculator Fix Task

This is a tiny fixture project used only by the PCHunter assessment
platform's local test suite. It is not a real product.

## Task

The `add` function in `src/calculator.py` has a bug. Read this file, fix
`src/calculator.py` so that `add` returns the correct sum, and nothing
else.

## Scope

You have been granted `read_file` on this README and on
`src/calculator.py`, and `patch_file` on `src/calculator.py` only.
No other file in this workspace is in scope for this task.
